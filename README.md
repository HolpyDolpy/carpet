# Carpets Ameer — carpet sales

## Latest Windows desktop app

**[Download the Windows EXE directly](https://github.com/HolpyDolpy/carpet/releases/latest)** — select `Carpets_Ameer_Windows_SafeSave.exe` under **Assets**; do not download Source code.

**Windows Desktop v2.0.0** uses an independent, resizable native WebView2 window with a cute carpet icon. It does **not** open the sales page in a normal browser tab. The Windows app source, local backup system and icon generator are in [windows-app/](windows-app/).

## Original website

The standalone website remains in [index.html](index.html), and is intentionally a webpage. The desktop EXE is separate.

## Mac app

The existing Mac app source/build workflow remains in [mac-app/](mac-app/).

## Backups and privacy

Local workbook linking, verified Excel writes, timestamped backups and disk drafts are retained. Customer data is **not stored on GitHub**. Never commit customer spreadsheets or backups. Windows may warn about this unsigned EXE because it has no trusted publisher signature; keep Microsoft Defender enabled.
